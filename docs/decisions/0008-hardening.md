# ADR 0008: Pilot hardening (M8)

**Status:** accepted for M8 · 2026-09-29

## Decisions

1. **Retention deletes bytes, not history.** A daily purge per company (and an on-demand dry run or purge for administrators) deletes file bytes past their retention period:
   - rejected files after 7 days;
   - source and derived files after `retention_days.source`;
   - report PDFs and exports after `retention_days.business`, counted from the last related email.

   Records, revisions, report figures, hashes, provenance and audit stay. A `*_purged_at` marker makes the UI answer 410 with an explanation instead of a broken link.
2. **Holds win.** An active hold on an upload, its batch or a report blocks the purge, and the run records SKIPPED_HOLD.
3. **The deletion manifest is the source of truth after a restore.** Every purge writes a PURGED `retention_event` with the exact storage keys. `app.cli retention-replay` deletes them again after a backup is restored, so deleted content is never resurrected. A failed deletion is recorded and the object stays eligible, so the next run retries it.
4. **Restore verification before sends.** `app.cli verify-restore` checks row counts, confirms every READY report PDF exists with its recorded checksum, confirms no manifest key is back in storage, and lists QUEUED/SENDING/UNKNOWN email intents to reconcile.
   - `SENDS_PAUSED` holds all outbound email in the queue without consuming attempts, so operators can restore and reconcile before anything is sent.
   - The local drill (`infra/local/restore_drill.py`) times backup, restore and verification and writes the evidence as JSON.
5. **Metrics are counts, gated by a token.** `GET /api/v1/ops/metrics` returns Prometheus text only when `METRICS_TOKEN` is configured (404 otherwise, 401 for a wrong token). It carries no identifiers or content. `infra/monitoring/alerts.yml` encodes the spec's thresholds. Administrators see the same health, plus their company's figures, on the Operations page.
6. **Security headers.**
   - The API sends `default-src 'none'; frame-ancestors 'none'`, `nosniff`, `no-referrer` and `no-store` on every response.
   - The web app sends a strict CSP in production builds only, allowing the object-storage origin for signed uploads, PDF preview and page images. Development needs `eval` for fast refresh.
   - The full E2E suite passes against the production build with the CSP on.
7. **ROI never assumes.** The baseline is whatever the company measured and entered. Pilot figures are computed from real timestamps and counts. A comparison appears only with a baseline, at least 10 reports and at least 14 days of data; otherwise the page says why.
8. **Evidence over claims.** Load, restore and accessibility results are generated by scripts and tests and stored under `docs/evidence/` or in test runs. They are measurements on a developer laptop, not production capacity statements.
